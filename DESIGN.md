# Design System

The app's UI is built on [shadcn/ui](https://ui.shadcn.com) components themed
by CSS design tokens. **All colors, radii, and fonts live in one place:**
[`src/app/globals.css`](./src/app/globals.css). Components never hardcode
colors.

Preview everything at **`/design-system`** (dev-only page).

## Tokens

Defined in `globals.css` under `:root` (light) and `.dark` (dark, defined but
not yet toggled). Each token is exposed to Tailwind via `@theme inline`, so
you use them as normal utilities.

| Token | Light value | Use for | Utilities |
|---|---|---|---|
| `background` | `#f9f2ec` warm cream | page background | `bg-background` |
| `foreground` | `#171515` near-black | body text | `text-foreground` |
| `card` | `#ffffff` | card surfaces | `bg-card text-card-foreground` |
| `primary` | `#171515` | primary buttons, emphasis | `bg-primary text-primary-foreground` |
| `secondary` | `#f5f5f5` | secondary buttons | `bg-secondary text-secondary-foreground` |
| `muted` | `#f2e9dd` | subdued surfaces | `bg-muted` |
| `muted-foreground` | `#6e6c66` | secondary text | `text-muted-foreground` |
| `accent` | `#f6ead7` | hover surfaces (menus) | `bg-accent` |
| `destructive` | `#dc2626` | delete/danger | `bg-destructive`, `text-destructive` |
| `border` / `input` | `#f2e2c4` warm sand | borders, input outlines | `border-border` |
| `ring` | `#171515` | focus rings | automatic on focus |
| `deck-sky` | `#e8f4ff` | deck/feature pastel 1 | `bg-deck-sky` |
| `deck-mint` | `#cff7d3` | deck/feature pastel 2 | `bg-deck-mint` |
| `deck-blush` | `#fdd3d0` | deck/feature pastel 3 | `bg-deck-blush` |
| `bubble-assistant` | `#efefef` | AI chat bubbles | `bg-bubble-assistant` |
| `bubble-user` | `#dff5e8` | user chat bubbles | `bg-bubble-user` |

**Radius scale** (Figma): `rounded-sm` 8px · `rounded-md` 12px · `rounded-lg`
16px · `rounded-xl` 20px. Derived from `--radius: 1rem` — change one variable
to scale the whole app.

**Font**: Inter, loaded in `src/app/layout.tsx` via `next/font` as
`--font-inter`, consumed by `--font-sans`.

## Components

### `src/components/ui/` — shadcn primitives
Generated by the shadcn CLI but **owned code — edit freely**. Current set:
`button` (variants: default/outline/secondary/ghost/destructive/link; sizes:
default/compact/xs/sm/lg/icon…), `card` (+ Header/Title/Description/Content/
Footer), `input`, `textarea`, `label`, `badge`, `skeleton`, `dialog`,
`alert-dialog`, `dropdown-menu`, `separator`, `progress`, `sonner` (toasts).

Note: `button` is customized — default size is `h-11 px-5` and radius is
`rounded-sm` (8px) to match the app's Figma look.

**Audio/voice components** (from the [`@elevenlabs-ui`](https://ui.elevenlabs.io)
registry, configured in `components.json`): `audio-player` (+ provider/hooks),
`waveform` (Static/Scrolling/Microphone/Recording variants), `live-waveform`,
`bar-visualizer`, `scrub-bar`, `voice-button`, `mic-selector`, `orb` (three.js),
`matrix`, `message`, `conversation`, `response`, `shimmering-text`, `avatar`.
Add more with `npx shadcn@latest add @elevenlabs-ui/<name>`. (Skipped:
`voice-picker`, `conversation-bar`, `speech-input`, `transcript-viewer` — they
require ElevenLabs's own API/SDK.)

### `src/components/shared/` — app composites
Built on the primitives: `spinner` (lucide Loader2 + CVA sizes),
`quick-actions` (dashboard action grid), `top-header` (fixed app bar),
`bottom-nav` (fixed tab bar).

Feature components live in `src/components/{auth,chat,flashcards}/`.

## Recipes

**Add a shadcn component**
```bash
npx shadcn@latest add <name>    # lands in src/components/ui/, then edit freely
```

**Change the palette** — edit `:root` (and `.dark`) in `globals.css` only.
Never touch component files for color changes.

**Add a variant to a component** — extend the CVA config, e.g. in `button.tsx`:
```ts
variants: {
  variant: {
    // ...existing
    warm: "bg-accent text-accent-foreground hover:bg-accent/80",
  },
}
```

**Enable dark mode** — the `.dark` token block already exists. Install
`next-themes` (already a dependency), wrap the app in `<ThemeProvider
attribute="class">`, and add a toggle. Nothing else changes.

**Toasts**
```ts
import { toast } from "sonner"
toast.success("Saved!")            // also .error, .loading + toast.dismiss(id)
```

## Hard rules

1. **No hex literals in components or pages.** Use token utilities.
2. **No inline `style={{}}` for colors.** (Layout measurements like
   `env(safe-area-inset-*)` are fine.)
3. **Semantic tokens over palette values** — `text-muted-foreground`, not
   `text-gray-600`.
4. **No runtime style injection** — put shared CSS in `globals.css`.
5. New UI starts from a `ui/` primitive; only build custom when no primitive
   fits (then use CVA for variants, like `shared/spinner.tsx`).
