# Design System Rules — moved

This file is no longer maintained. The design system reference lives in
**[DESIGN.md](./DESIGN.md)**, with a live preview at `/design-system` (dev only).

Its guidance was written against a stack the app no longer runs — Prisma +
SQLite, NextAuth, hand-rolled `ui/` components, a blue/purple palette, and the
Söhne typeface. All of that was replaced by the Supabase and shadcn/ui
migration; the app now uses Inter and the warm token palette defined in
`src/app/globals.css`. Following the old rules would produce UI that no longer
matches the app.

Still-current material — the bilingual, learning-focused, mobile-first and
accessibility principles, and the deck card spec — was carried over into
DESIGN.md. Nothing was lost; the full original text remains in git history.
